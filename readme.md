# Robolab7 Signals

Репозиторий содержит выполнение лабораторной работы №3 по обработке цифровых сигналов. В работе рассматриваются дискретное преобразование Фурье, восстановление аналитического представления сигнала, вейвлет-анализ, проектирование цифровых фильтров и обработка зашумленного ЭКГ-сигнала.

## Содержание работы

В проекте реализованы следующие этапы:

- ручной расчет ДПФ по формуле;
- построение амплитудного, фазового, действительного и мнимого спектров;
- выделение основных гармоник сигнала;
- восстановление сигнала по найденным гармоникам;
- построение графика ошибки восстановления;
- изменение временной структуры гармоник;
- построение скалограмм исходного и измененного сигналов;
- синтез КИХ-режектора с окном Блэкмана;
- синтез БИХ-режектора Чебышёва I рода;
- построение АЧХ и ФЧХ фильтров;
- построение карты нулей и полюсов БИХ-фильтра;
- ручная фильтрация сигнала через разностное уравнение;
- сравнение времени работы КИХ- и БИХ-фильтров;
- обработка ЭКГ-сигнала и расчет средней частоты сердечных сокращений.

## Основные файлы

`python_project/robolab7.ipynb` — основной Jupyter Notebook с выполнением лабораторной работы.

`python_project/signal_3.txt` — исходный дискретный сигнал для спектрального анализа и фильтрации.

`python_project/signal_ecg_3.txt` — зашумленный ЭКГ-сигнал для практической части.

`python_project/figures_lab3/` — графики, автоматически сохраняемые при выполнении ноутбука.

`latex_project/lab3_report_overleaf_fast.tex` — LaTeX-отчет, подготовленный для компиляции в Overleaf.

`latex_project/figures_lab3/` — копия графиков для подключения в LaTeX-отчете.

## Запуск Python-части

Перейдите в папку `python_project` и откройте ноутбук:

```bash
cd python_project
jupyter notebook robolab7.ipynb
```

После выполнения ячеек графики автоматически сохраняются в папку:

`python_project/figures_lab3`

## Компиляция отчета

Для сборки отчета в Overleaf нужно загрузить содержимое папки `latex_project`, включая:

- `lab3_report_overleaf_fast.tex`;
- папку `figures_lab3`.

Рекомендуемый компилятор в Overleaf:

- XeLaTeX
